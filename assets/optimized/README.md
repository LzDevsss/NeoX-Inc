# Imagens do site

Versões WebP das imagens originais em `assets/`, que continuam preservadas no repositório.

As 15 imagens passaram de 18.939.348 para 1.985.004 bytes (redução de 89,5%). A conversão usou qualidade 92, sem ampliar imagens: até 1.280 px nas cenas, 800 px nos perfis e 256 px no logo, com modo near-lossless para o logo. Os vídeos não foram recomprimidos.

Ao atualizar uma imagem, conferir visualmente a versão WebP e a original, manter a proporção e executar a build para verificar os caminhos.
